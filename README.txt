富士雪國 App 外殼(放在 GitHub Pages)

1. 打開 index.html,把 EXEC_URL 的引號裡貼上 Apps Script 的網址(結尾是 /exec)。
2. 在 GitHub 建一個新的 repository(例如 fuji-snow),把這個資料夾裡的所有檔案上傳到最外層。
3. Settings → Pages → Source 選 Deploy from a branch,Branch 選 main、資料夾選 / (root),儲存。
4. 等一兩分鐘,網址是 https://你的帳號.github.io/fuji-snow/
5. 用手機開這個網址,加到主畫面:
   iPhone:Safari → 分享 → 加入主畫面。
   Android:Chrome → 選單 → 安裝應用程式 / 加到主畫面。
